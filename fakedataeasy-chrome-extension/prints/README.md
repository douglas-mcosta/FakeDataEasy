# Capturas para a Chrome Web Store

Requisitos Google: **até 5** imagens, **1280×800** ou **640×400**, **JPEG** ou **PNG 24 bits** (sem transparência).

As imagens nesta pasta foram normalizadas para **1280×800**, **PNG RGB** (sem alfa), com barras brancas se o rácio original for diferente.

Para voltar a gerar após substituir capturas de ecrã:

```bash
npm run prints:normalize
```
