Comece em três passos

Instalação simples, configuração objetiva e uso imediato.

  1. Instale pela Chrome Web Store

    Use a página Instalar para acessar o link oficial da extensão.

  2. Abra o popup ou configure os atalhos

    Você pode começar pelo menu principal ou ajustar comandos globais no painel de extensões do Chrome.

  3. Autorize sites se quiser usar o helper

    Atalhos e popup já funcionam sem isso; o helper é opcional e controlado por origem.

Perguntas frequentes

Os dados gerados vão para algum servidor?

Não. A geração acontece localmente e as preferências ficam salvas no dispositivo por meio de chrome.storage.local.

Preciso liberar todos os sites para usar a extensão?

Não. Popup e atalhos funcionam sem isso. A lista de sites é necessária apenas para o helper de preenchimento ao lado dos campos.

Posso exportar os valores gerados?

Sim. Alguns geradores mantêm histórico de sessão para exportação CSV em UTF-8 com BOM.

Serve para produção?

O foco é desenvolvimento, homologação e testes. A proposta não é criar identidades reais, e sim dados fictícios úteis para validar fluxos.
