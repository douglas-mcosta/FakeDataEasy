Loja oficial, fluxo conhecido e poucos cliques para sair da instalação e começar a testar.

Obter na Chrome Web Store

Este é o canal principal para instalar a extensão. Depois disso, você já pode usar o popup e os atalhos. A lista de sites só entra em cena se quiser habilitar o helper nos campos.

Abrir na loja

Se você estiver em um ambiente corporativo com políticas restritas, o comportamento final ainda depende das regras do navegador administrado.

Fluxo recomendado Chrome Web Store

Instalação oficial, atualizações futuras e experiência alinhada ao padrão do Chrome.

Como instalar

Três passos curtos para começar a gerar dados fictícios no navegador.

  1. Abra a página da extensão na loja

    Use o botão acima para abrir a listagem oficial do Fake Data Easy.

  2. Clique em “Usar no Chrome”

    Revise as permissões solicitadas e conclua a instalação no fluxo normal do navegador.

  3. Abra o popup e comece a usar

    Se quiser o helper, depois adicione os sites desejados nas opções da extensão.

O que vale saber antes de instalar

Sem surpresa: aqui está o essencial para entender como o produto se encaixa no seu navegador e no seu fluxo de trabalho.

Feito para Chrome e Chromium

O alvo principal é o Google Chrome. Outros navegadores baseados em Chromium podem funcionar, mas o foco do pacote é o ecossistema Chrome.

Atalhos dependem das regras do Chrome

Os comandos globais seguem as limitações de segurança do navegador e podem exigir ajuste no painel de atalhos das extensões.

Helper é opcional

Você não precisa liberar sites para usar o básico. Isso só importa se quiser os botões Auto e Escolher junto aos campos.
