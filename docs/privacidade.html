Privacidade explicada de forma objetiva, sem juridiquês desnecessário

Esta página resume como o Fake Data Easy lida com geração local, permissões do Chrome e armazenamento de preferências. O ponto central continua o mesmo: funcionar sem depender de backend próprio para o fluxo principal.

Geração local Os dados fictícios são gerados no dispositivo, não em servidores do autor.
Sem telemetria integrada A extensão não envia analytics nem coleta uso para terceiros.
Permissões com finalidade clara Cada permissão existe para popup, atalhos, helper opcional ou preferências locais.

Resumo

O Fake Data Easy gera valores fictícios localmente, salva preferências no navegador e não depende de login ou conta para o uso principal.

O que não fazemos

Não vendemos dados, não exigimos cadastro e não enviamos para servidores próprios os valores gerados, o conteúdo das páginas ou o que você copia.

Atualizações

Se novos recursos exigirem mudanças nesta política ou em permissões declaradas, este site e o arquivo PRIVACY.md serão atualizados.

Mais contexto, sem complicar

Abaixo estão os pontos principais do comportamento da extensão, alinhados ao documento de privacidade do repositório.

Dados e rede

  • Não há contas, login nem telemetria embutida na extensão.
  • Os valores gerados e copiados existem no fluxo local do navegador.
  • Não há carregamento remoto de scripts para o funcionamento principal da extensão.

Permissões do Chrome

Permissão Finalidade
activeTab Ler o URL da aba atual ao adicionar um site e permitir ações sob gesto explícito do usuário.
scripting Registrar o helper apenas nos hosts autorizados pelo usuário.
storage Salvar localmente lista de sites, tema, preferências do helper e dados de sessão para exportação.
clipboardWrite Copiar para a área de transferência o valor que acabou de ser gerado.
offscreen Suportar cópia confiável a partir do service worker em atalhos globais.
tabs Abrir a página de opções quando o usuário escolhe configurar ou gerenciar a lista.

Helper nos campos

O helper só roda nas origens da sua lista e pode ser desligado totalmente. Ele usa atributos do campo localmente para heurísticas e regras definidas por você, sem transmitir esse conteúdo para servidores externos.

Armazenamento local

As informações ficam no chrome.storage.local do perfil do navegador até você limpar os dados da extensão ou desinstalá-la.

Contato

Questões sobre privacidade podem ser enviadas pelo GitHub Issues ou pelos canais públicos da Chrome Web Store.
